# Background music

Drop royalty-free music files here (`.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`, `.flac`).
The Master Agent Studio (`/studio.html`) lists them in the **Music track** menu; the
first file is the default. Tracks are looped to fit the video and automatically
lowered (ducked) whenever the narrator speaks.

With no files here, the agent generates a soft ambient music bed with FFmpeg, so
no music API or licence is needed.

Only use music you have the rights to publish on YouTube.
